# 历年《国务院政府工作报告》全文（2000–2026）

每年一个 Markdown 文件，放在 `md/`；总览见 [`index.md`](index.md)、[`index.csv`](index.csv)、[`index.json`](index.json)。

| 项目 | 内容 |
| --- | --- |
| 覆盖范围 | 2000–2026，共 **27** 份，无缺年 |
| 正文总量 | 约 50.4 万字（去空白） |

## 来源

优先用中国政府网（`gov.cn`）；公报数字库缺失的年份用**辽宁省人民政府「国务院政府工作报告」专栏**的官方转载补齐。

| 年份 | 来源 |
| --- | --- |
| 2000、2002–2007、2023–2026 | 中国政府网 · [国务院公报](https://www.gov.cn/gongbao/) |
| 2014–2017 | 中国政府网 · [国务院](https://www.gov.cn/guowuyuan/) |
| 2013 | 中国政府网（2014 两会人大专题） |
| 2018–2022 | 中国政府网 · [总理](https://www.gov.cn/premier/) |
| **2001、2008–2012** | [辽宁省人民政府（转载）](https://www.ln.gov.cn/web/zwgkx/zfgzbg/zyzfgzbg/index.shtml) |

> 为什么会用到省级站点：中国政府网历年两会专题页在站点改版后大量 404（`/2010lh/`、`/govweb/` 等旧路径已下线），而国务院公报数字库只索引到 2000、2002–2007、2018 年以后，2001 与 2008–2012 这 6 年在中央站点已无可用全文页。辽宁省政府专栏是官方转载的完整全文，作为兜底来源并在索引中逐条标注。

## 校验

每条都过了以下自动检查，`index.csv` 的「校验」列记录结果（当前全部为 `OK`）：

- 正文 ≥ 4000 字，且含「各位代表」
- 报告日期与文件名年份一致
- 会议名与「YYYY年M月D日在第N届全国人大第M次会议上」锚定（避免正文提到往届会议时误判）
- 首段为「各位代表：」、末段以句末标点结尾（无截断）
- 无省略号引导、无图片说明、无「责任编辑/相关新闻/详细阅读」等页面导航残留

**交叉校验**：2025、2024 两年用中国政府网两个不同页面（公报版 vs 要闻版）分别解析，规范化后逐字**完全一致**（各 16442 / 15521 字，相似度 1.0000）。

## 复现 / 扩展

```bash
python3 fetch_reports.py                 # 全量重新抓取
python3 fetch_reports.py 2025 2024       # 只抓指定年份
python3 fetch_reports.py --offline       # 用 raw/ 里的快照离线重建，不联网
```

新增年份只需在 `fetch_reports.py` 的 `MANIFEST` 里加一行 `(年份, URL, 来源标签, 类型)`。

## 已知边界

- **1954–1999 未包含**。这段时期只有国务院公报的**整期 PDF**（如 [`gwyb199908.pdf`](https://www.gov.cn/gongbao/shuju/1999/gwyb199908.pdf)），没有单篇 HTML，需要逐期下载 PDF 抽正文（本机 PyMuPDF 可用），早期年份可能是无文字层的扫描件、需要 OCR。需要的话可以续做。
- 各年报告正文基本不含图表；报告附带的《计划报告》《预算报告》是另外的独立文档，未收录。
- 辽宁转载页的年份（2001、2008–2012）末尾保留原刊的「注释／附注」条目，与公报版本体例一致。
